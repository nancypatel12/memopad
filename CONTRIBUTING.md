# Contributing

Contributions are welcome. Memopad stays small on purpose, so:

- Open an issue before a big change, so we can agree on it first.
- Keep each pull request to one change, with tests for anything in `src/lib/`.
- No dependencies, no build step, no network requests.
- Keep the look: the same colours, fonts and popup size.
- If you change `research/`, rerun the evaluation and update `research/results.txt`.

Run `npm test` before opening a pull request. CI runs it too.

By contributing, you agree to share your changes under the same license as Memopad.

## Using AI tools

You're welcome to use AI tools to understand the code, help write it, or run experiments. But you must understand everything you submit and be able to explain it. Write comments and pull request descriptions in your own words.
